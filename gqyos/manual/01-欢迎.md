# 欢迎来到 GQYOS

GQYOS 是为顾清影打造的 AI 驱动 Arch Linux 系统。

## 快速开始

1. 运行 `gqyos doctor` 检查系统状态
2. 运行 `gqyos update` 更新系统
3. 运行 `gqyos logo` 查看系统标识

## 核心命令

| 命令 | 功能 |
|------|------|
| `gqyos update` | 更新系统和 GQYOS |
| `gqyos doctor` | 系统诊断 |
| `gqyos migrate` | 运行迁移 |
| `gqyos logo` | 显示 Logo |
| `gqyos version` | 版本信息 |

## 目录结构

```
~/.config/           # 配置文件
/usr/share/gqyos/    # GQYOS 系统文件
/usr/bin/gqyos-*     # GQYOS 命令
```
