# GQYOS 快捷键

## Hyprland

| 快捷键 | 功能 |
|--------|------|
| `Super + Enter` | 终端 |
| `Super + Q` | 关闭窗口 |
| `Super + D` | 启动器 |
| `Super + E` | 文件管理器 |
| `Super + 1-9` | 工作区 |
| `Super + V` | 浮动切换 |
| `Super + M` | 退出 |

## Tmux

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+a + c` | 新窗口 |
| `Ctrl+a + n/p` | 切换窗口 |
| `Ctrl+a + 方向键` | 切换面板 |

详见: https://wiki.hyprland.org/Configuring/Binds/
